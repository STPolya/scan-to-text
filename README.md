# Scan to Text (консольная версия)

Консольное Python-приложение для распознавания печатного текста
и обработки изображений таблиц с помощью Tesseract OCR.

**Проект находится в разработке.** Реализованы распознавание
одного или нескольких изображений и сохранение результатов
в TXT, DOCX, PDF и XLSX.

## Версии проекта

- `main` — консольное приложение.
- `fastapi-integration` — веб-приложение с интерфейсом.

Версии развиваются отдельно и имеют собственные README.

## Реализовано

- Ввод путей к одному или нескольким изображениям.
- Выбор языка: русский, английский или русский + английский.
- Вывод распознанного текста в консоль.
- Сохранение текста в TXT.
- Сохранение текста в документ Word.
- Создание поискового PDF из исходного изображения.
- Разбиение распознанного текста таблицы на строки и элементы.
- Сохранение полученных данных в Excel.
- Возможность пропустить сохранение или завершить программу.
- Итоговая статистика обработки и сохранения.
- Локальный журнал ошибок в формате JSON Lines.


## Технологии

- **Python** — логика приложения.
- **Tesseract OCR** — движок распознавания текста.
- **pytesseract** — взаимодействие с Tesseract из Python.
- **Pillow** — чтение изображений.
- **python-docx** — создание документов Word.
- **XlsxWriter** — создание файлов Excel.
- **logging** и **json** — структурированное логирование.


Tesseract устанавливается отдельно. Для русского и английского
текста необходимы языковые данные `rus` и `eng`.

[Инструкция установки Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html)

Путь к исполняемому файлу Tesseract задаётся в `main.py`
и должен соответствовать его расположению на компьютере.

## Логирование

Ошибки распознавания и сохранения записываются в `logs/errors.log`.
Каждая строка — отдельный JSON-объект с временем события,
операцией, путём к файлу, типом и описанием ошибки.

Журналы исключены из Git. В папке `logs` отслеживается только `.gitkeep`.

## Планируется

- Улучшение распознавания за счёт предварительной обработки изображений.
- Улучшение определения строк и столбцов таблиц.
- Автоматическое определение языка с возможностью ручного выбора.
- Развитие проверок и обработки ошибок.

## Ограничения

- Приложение ориентировано на качественные изображения печатного текста.
- Рукописный текст, размытие, блики и наклон могут ухудшать результат.
- Распознанный текст требует проверки пользователем.
- Изображения обрабатываются последовательно.
- Оформление исходного документа в TXT и DOCX не восстанавливается.
- Обработка таблиц основана на разделении строк по пробельным символам:
  ячейки из нескольких слов и пустые ячейки могут обрабатываться неверно.
- Пути вводятся через запятую, поэтому запятые в именах файлов
  в текущем способе ввода не поддерживаются.
- Сохранение по существующему пути перезаписывает файл.
